# Regression Strategy
Every pull request runs backend/API/GraphQL checks and Chrome smoke after services become healthy. A merge to `main` runs the same gate and retains HTML/JUnit artifacts. Targeted regression adds cases mapped to changed requirements and adjacent authorization/database boundaries. Before release, run the full suite, MySQL reconciliation, responsive viewports, Firefox critical journey, Postman/Newman, and a controlled Locust sanity test. Smoke failure stops promotion; a flaky test is quarantined only with an owner, defect, risk assessment, and replacement coverage—never silently retried into green.
