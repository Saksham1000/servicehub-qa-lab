# Quality Metrics
Use evidence, numerator/denominator, date, build, and scope. Execution progress = executed/planned; pass rate = passed/executed excluding blocked; requirement coverage = requirements with tests/total; automation coverage = stable automated candidates automated/total candidates; defect density = confirmed defects per agreed size unit; leakage = post-release defects attributable to release/total; reopen rate = reopened/closed; failed regression count is the number of previously passing behaviors now failing. Never compare rates across releases without equivalent scope and never replace risk judgment with a single percentage. This portfolio supplies the measurement structure but claims no production figures.
